# Software Craftsmanship

## Manifesto

> **"Not only working software, but also well-crafted software."**

## Values

- **Professionalism** over "good enough"
- **Pride in one's work** over shipping fast
- **Quality as a habit** not a phase

## Practice

- Code is a craft, not just typing
- Continuous improvement
- Mentorship and knowledge sharing
- Learning from mistakes

## Integration with Vibe Coding OS

Software craftsmanship is the **philosophical foundation** of [[the-antidote]].
