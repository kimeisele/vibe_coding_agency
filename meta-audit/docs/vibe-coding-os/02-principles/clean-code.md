# Clean Code

## Principle

Code should be:
- Easy to understand
- Easy to modify
- Easy to extend

## Key Ideas

### Read > Write
Code is read 10x more than written. Optimize for reading.

### Self-Documenting
Good names eliminate need for comments.

### Small Functions
Functions should do one thing well.

### No Surprises
Code should behave as expected from its name.

## The Boy Scout Rule

See: [[boy-scout-rule]]

> "Leave code cleaner than you found it."
