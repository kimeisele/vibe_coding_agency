# The Pragmatic Programmer

## Core Principles

### 1. Take Responsibility
Own your code. Don't blame tools or teammates.

### 2. Fight Software Entropy
Fix broken windows immediately. Don't let decay spread.

### 3. DRY - Don't Repeat Yourself
See: [[dry-principle]]

### 4. Make It Easy to Reuse
Good code is reusable code.

## Pragmatic Thinking

- Think critically about AI suggestions
- Question assumptions
- Test early and often
- Automate everything
