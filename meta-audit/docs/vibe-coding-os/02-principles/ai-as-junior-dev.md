# Treat AI as a Junior Developer

## Principle

> **AI should be treated as a junior developer who requires constant supervision.**

## What AI Is Like

### Strengths (Like a Junior Dev)
- ✅ Knows syntax
- ✅ Generates code quickly
- ✅ Follows patterns
- ✅ Writes tests (when asked)

### Weaknesses (Like a Junior Dev)
- ❌ Doesn't understand business context
- ❌ Can't make architectural decisions
- ❌ Needs senior review
- ❌ May introduce security vulnerabilities
- ❌ Lacks domain knowledge

## Implications

**You wouldn't:**
- ❌ Let junior dev ship code without review
- ❌ Let junior dev make architectural decisions
- ❌ Trust junior dev with security-critical code
- ❌ Accept junior dev's first solution as final

**Same applies to AI.**

## Best Practices

1. **Provide Context** - Like onboarding a junior dev
2. **Review Everything** - Use [[clear-framework]]
3. **Supervise Constantly** - Don't trust blindly
4. **Teach Standards** - Include style guide in prompts
