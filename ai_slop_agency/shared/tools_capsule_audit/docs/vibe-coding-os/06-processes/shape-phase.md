# Shape Phase

## Goal

Define **boundaries and risks** without implementation details.

## Duration

**1-2 days** (not weeks)

## Responsible

**Architect / Tech Lead**

## Outputs

### 1. Appetite
Fixed time budget

Example: "6 days, not 6 weeks"

### 2. Pitch
See: [[10-templates/pitch-template]]

Contains:
- Problem
- Appetite
- Solution (high-level)
- Rabbit Holes
- No-Gos

### 3. Architecture Diagram
Visual representation of components

### 4. Boundaries
- ✅ In scope
- ❌ Out of scope

## Key Principle

> **"Shape is NOT a detailed spec. High-level only."**

Provide **direction**, not **instructions**.
