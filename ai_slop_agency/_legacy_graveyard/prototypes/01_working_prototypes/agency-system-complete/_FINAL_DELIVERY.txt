2. Start Server:
   python cli/main.py serve --port 5000

3. Test:
   curl http://localhost:5000/health
   
4. Run Workflow:
   python cli/main.py run test-project \
     --request "My Django app is slow" \
     --tech-stack django

HOW IT WORKS (Simple Version)
================================================================================

Customer Problem
    ↓
Claude Code starts Agency analysis
    ↓
API calls NotebookOrchestrator
    ↓
Papermill injects parameters into template
    ↓
Jupyter notebook executes 4 phases:
    1. Parse request
    2. Web research (Claude API)
    3. Code scanning (real tools)
    4. Generate professional report
    ↓
JSON with findings returned to Claude Code
    ↓
Claude Code interprets findings
    ↓
Claude Code decides next steps
    ↓
Customer gets proposal + action plan

(This happens in ~5-10 minutes, not days)

INTEGRATION OPTIONS (Pick One)
================================================================================

Option 1: REST API (Recommended for Agents)
   Client: requests.post("http://localhost:5000/api/v1/run", json={...})
   How: HTTP JSON requests/responses
   Best for: Any language, remote execution

Option 2: Python SDK (Direct Import)
   Client: from orchestrator.core import NotebookOrchestrator
   How: Python method calls
   Best for: Python-only projects, fast loops

Option 3: CLI (Human or Script)
   Client: agency run project --request "..."
   How: Command-line interface
   Best for: Quick tests, shell scripts

All three work. Pick what fits your workflow.
