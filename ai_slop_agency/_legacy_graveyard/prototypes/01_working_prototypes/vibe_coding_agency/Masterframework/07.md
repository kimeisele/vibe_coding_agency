## Anti-Patterns Found

### ANTI-001: Empty Exception Handler

**Location**: `src/utils/helpers.py:123`

```python
try:
    risky_operation()
except Exception:
    pass  # ❌ Silently swallows errors
```

**Fix**: Log error or re-raise with context

### ANTI-002: Mutable Default Argument

**Location**: `src/models/user.py:45`

```python
def add_tags(self, tags=[]):  # ❌ Mutable default
    self.tags.extend(tags)
```

**Fix**:

```python
def add_tags(self, tags=None):
    if tags is None:
        tags = []
    self.tags.extend(tags)
```
