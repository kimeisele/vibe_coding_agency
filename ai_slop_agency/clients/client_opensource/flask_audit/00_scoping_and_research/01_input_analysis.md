# Flask Application Audit

## Project Description
A simplified Flask web application with multiple security and code quality issues.

## What we're analyzing
- Python Flask application
- Focus: Security vulnerabilities and code quality
- Scope: Single app.py file

## Tools to use
- bandit: Security scanning
- flake8: Code style and quality
- radon: Complexity analysis

## Success criteria
- Identify security issues (hardcoded secrets, injection vectors)
- Identify code quality problems (style, complexity)
- Provide actionable remediation steps
