## Critical Issues (Detail)

### 🔴 CRITICAL-1: Extreme Cyclomatic Complexity
**Module:** `agency_toolkit/commands/os.py`
**Pattern:** God Function
**Impact:** Functions with very high complexity are prone to errors, hard to test, and difficult for new developers to understand. Refactoring is critical for long-term stability.

**Evidence:**
```python
# agency_toolkit/commands/os.py (Simplified view of execute_project_workflow)
def execute_project_workflow(
    project_name: str,
    archetype_id: str,
    solution_id: str,
    module_id: str,
    ai_provider: str | None = None,
    stop_on_error: bool = True,
) -> dict:
    # ... (initial loading and validation)

    # Find archetype
    archetype = next((a for a in archetypes if a["id"] == archetype_id), None)
    if not archetype:
        raise ValueError(...)

    # Find solution
    solution = next((s for s in solutions if s["id"] == solution_id), None)
    if not solution:
        raise ValueError(...)

    # Verify solution matches archetype
    if solution["archetype_id"] != archetype_id:
        raise ValueError(...)

    # ... (and so on, with deep nesting and multiple exit points)
```
**Root Cause:** Violates SRP - the function does too many things: loading registry data, validating all IDs, verifying associations, resolving dependencies, building a context object, and then orchestrating execution.

**Metrics:**
- Cyclomatic Complexity: 22 (Rank D) for `execute_project_workflow` and `_interactive_workflow`.
- LOC: `agency_toolkit/commands/os.py` is the largest file with 583 LOC.
- Fix Effort: **LARGE**

**Fix Strategy:**
1.  **Extract Validation Logic:** Create separate functions for finding and validating archetypes, solutions, and modules (e.g., `find_and_validate_archetype(id)`).
2.  **Extract Context Building:** Use a dedicated builder function or class to assemble the `context` dictionary.
3.  **Simplify Control Flow:** The main function should delegate to these new functions, making the primary control flow much clearer and reducing nesting.
4.  Estimated: 8-12 hours.

**Dependencies Affected:** `cli_app.py` and the `os_init` function within the same file.

### 🔴 CRITICAL-2: Bare Except Clauses
**Module:** `agency_toolkit/core/social/rendering.py`
**Pattern:** Overly broad exception handling
**Impact:** Catching all exceptions (including system-level ones) can lead to the application failing in silent or unexpected ways. This makes debugging extremely difficult.

**Evidence:**
```python
# agency_toolkit/core/social/rendering.py
# In function load_font
try:
    font = ImageFont.truetype(str(font_path), size=size)
except:  # This is a bare except
    ...
```
Ruff found two instances of `E722` (Do not use bare `except`) in this file.

**Metrics:**
- Occurrences: 2
- Fix Effort: **SMALL** (1h)

**Fix Strategy:**
1. Identify the specific exceptions that `ImageFont.truetype` can raise (e.g., `IOError`).
2. Replace `except:` with `except (IOError, OSError) as e:`.
3. Log the specific error `e` to aid in debugging.

**Dependencies Affected:** `core/social/generator.py`
