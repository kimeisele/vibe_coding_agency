### Task 1.5: Refactor load_config to Orchestrate

**AI Agent Instructions:**
```python
ACTION: Refactor
FILE: agency_toolkit/utils.py
FUNCTION: load_config

NEW STRUCTURE:
def load_config() -> Config:
    """Load and validate configuration (orchestrator function).

    Flow:
        1. Load file → _load_config_file()
        2. Merge env → _merge_env_vars()
        3. Apply defaults → _apply_defaults()
        4. Validate → Pydantic Config model
        5. Handle errors → clear error messages

    Returns:
        Validated Config object

    Raises:
        ValueError: If config is invalid (with helpful message)
    """
    try:
        # Step 1: Load file
        file_config = _load_config_file() or {}

        # Step 2: Merge env vars
        merged = _merge_env_vars(file_config)

        # Step 3: Apply defaults
        complete = _apply_defaults(merged)

        # Step 4: Validate with Pydantic
        return Config(**complete)

    except Exception as e:
        # Clear error message for user
        raise ValueError(f"Config error: {e}") from e

GOAL:
- Main function is now just orchestration
- Each step is a single function call
- Complexity should be CC < 6
```

**Validation:**
