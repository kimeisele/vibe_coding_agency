## VALIDATION CHECKLIST

AI must verify before proceeding to ARCHITECTURE_DESIGN:

- [ ] Problem statement is clear and specific
- [ ] At least 3 core functional requirements defined
- [ ] At least 3 success metrics with measurable targets
- [ ] Technical constraints identified (even if “none”)
- [ ] Scope explicitly defines what is OUT of scope
- [ ] No contradictory requirements
- [ ] User has confirmed/approved (if interactive)
